# Snake Game

Classic Snake Game built with JavaScript.

## Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)

## Features

- Score system
- Game over detection
- Keyboard controls
- Responsive canvas
- Restart functionality

## How to Play

- Use arrow keys to move the snake
- Eat food to grow
- Don’t hit walls or yourself

## Installation

```bash
open index.html
```
